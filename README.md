## 🚀 Who We Are

TMI is a student-led development collective where ambition meets opportunity. We are a
**Student Development Platform** that delivers real-world results:

- 🏢 **Enterprise Web Services** - We build production-grade websites and digital services for
  large companies and organizations.
- 🏆 **Tech Competitions** - We organize and host coding contests, hackathons, and innovation
  challenges to grow the next generation of builders.
- 🎓 **Student Growth** - Real projects, real clients, real skills. Members learn by shipping.
